#
#     python -m pip install -r tools/requirements.txt -r tools/requirements-cad.txt \
#         -c tools/constraints-cad.txt pytest
#
# SECURITY-STANDARDS.md: a transitive dependency is a new dependency, and
# versions are pinned. A constraint only applies to a package that something
# else asks for, so this file adds nothing on its own; it stops a new release
# of an indirect dependency from changing the job between two runs.
#
# Licences are as each package's metadata declares them (the SPDX expression
# where one is given, otherwise the trove classifier), read from the installed
# distributions. That is a record, not a legal review.
# Measured 2026-09-25: this exact set is what Python 3.14 on macOS arm64
# installs, and it resolves unchanged on Python 3.12 for Linux x86_64 and
# aarch64 (pip download with this file). As wheels it is 287 MB on Linux
# x86_64 and 269 MB on aarch64, of which vtk is 146 MB and 136 MB.
